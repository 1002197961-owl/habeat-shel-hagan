# ספריית שירים — גרסה ראשונה

עודכן: 18 בספטמבר 2026.

## מה עובד

- `/library`: נגן שמע אמיתי אחד, הפעלה/השהיה, דילוג בזמן, מהירות וחזרה בלולאה.
- שלושה קטעים מקוריים ללא שירה: בוקר של צלילים, טיפות רוקדות, מצעד הצבעים.
- קובצי WAV נוצרים בשרת מתווים קבועים; אין תלות בשירות מוזיקה חיצוני.
- חיפוש בעברית גם עם ניקוד, סינון נושא, סינון קטעים זמינים ודפדוף בארבעה כרטיסים.
- מועדפים נשמרים במכשיר. כשל בשמירה מוצג למשתמשת.
- ליווי קצב מוצע מסתנכרן לזמן הנגן, כולל בהשהיה ובשינוי מהירות.
- חמשת השירים המוכרים הם פריטי קטלוג הממתינים לקובץ שמע. אין להציגם כהקלטות זמינות.

## חיבור Supabase שהוכן

- `supabase/migrations/*_song_catalog.sql`: קטלוג משותף, RLS ואחסון שמע פרטי.
- `supabase/seed.sql`: שמונה פריטי פתיחה, ללא שינוי פריטים קיימים בהרצה חוזרת.
- `lib/server/songCatalog.ts`: טעינה בצד השרת באמצעות publishable key בלבד.
- `app/api/songs/[id]/audio/route.ts`: שמע מקורי או קישור Storage חתום לשעה.
- משתני הסביבה: `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` כמפורט ב־`.env.example`.
- בעת כשל בענן מוצגים קטעי הבסיס לצד הודעה מפורשת. מצב זה אינו נחשב לחיבור תקין.

## גבולות הרשאות

הקטלוג מיועד לתוכן לימודי משותף ללא נתונים אישיים. תפקידי anon ו־authenticated יכולים לקרוא רק פריטים שפורסמו. אין להם הרשאות לשנות את הקטלוג או להעלות קבצים.

ה־bucket `song-audio` פרטי. קריאת אובייקט מותרת רק אם פריט קטלוג שפורסם מפנה אליו ו־`rights_status = 'cleared'`. קישור חתום תקף לשעה; הסרת פרסום חוסמת יצירת קישורים חדשים, אך קישור שכבר נוצר עשוי להישאר תקף עד פקיעתו.

זה אינו אחסון להקלטות ילדים, מידע פרטי או רישיונות המוגבלים לגן מסוים. אלה דורשים מודל גנים וכניסה מאומתת נפרדים. עורכים מוסיפים קבצים דרך לוח הבקרה של הפרויקט עד שתיבנה כניסת עורך באפליקציה.

## מצב חיבור אמיתי

בעת הבנייה נמצא בחיבור Supabase רק הפרויקט הלא־פעיל `SkillUp Ashdod`. הוא שייך למוצר אחר ולא שונה. עדיין לא נוצר פרויקט עבור הביט של הגן ולא הוחלו בו migrations. נדרשת בחירת הארגון לפני יצירת פרויקט, ובהמשך אישור העלות שהמערכת תציג.

לאחר הבחירה: ליצור פרויקט ייעודי, להחיל migration ו־seed, לבדוק קריאה בתפקיד anon וחסימת כתיבה, להריץ Supabase security advisors, לחבר את משתני הסביבה ולבדוק קובץ שמע דרך Storage. אין להגדיר service_role או secret key בנגן.

## בדיקות

בדיקות Vitest בודקות יצירת WAV עם אות שמע לא־רווי, משך נכון, byte ranges לדילוג, חיפוש, סינון, אימות רשומות, fallback ודחיית מפתח privileged.

בדיקות PGlite מריצות Postgres אמיתי מקומית ומאמתות: הסתרת טיוטות, חסימת עריכה/מחיקה/העלאה, מדיניות אובייקטים וחסימת פרסום קובץ שלא אושר. מעטפת טבלאות Storage בבדיקה מדומה; זו אינה בדיקת Storage API בענן.

מקורות: [Supabase — Storage buckets](https://supabase.com/docs/guides/storage/buckets/fundamentals), [Signed URLs](https://supabase.com/docs/reference/javascript/storage-from-createsignedurl), [MDN — media playback](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play).
