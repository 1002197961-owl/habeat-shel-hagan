## הפעלה למפתח או לבודק עם סביבת קוד

```sh
npm ci
npm run build
npm run dev
```

פותחים את כתובת localhost שמדווחת הפקודה → מצב גננת → „התור שלי, התור שלך — בדיקת חיבור כלי”. בשרת dev מוצג local-development; בדיקת מועמד מזוהה נעשית מפלט build. `npm run test:e2e` מפעיל שרת זמני ובדיקות Chromium/WebKit מותקנים, ו־`npm run capture:screens` מצלם את פלט out. אין בפקודות פריסה או העלאת נתוני ילד.

## הפעלה ללא חומרה

1. באבחון המבוגר בוחרים „הדמיה לפיתוח בלבד”, ורמת סבב „פעולה אחת”. אפשר לסגור את פאנל המבוגר כדי לראות את משטח הילד בלבד.
2. לוחצים „התחילו”, שומעים את צליל ההדגמה וממתינים ל„התור שלך”. לוחצים „פעולת הדמיה”: מתקבלים צליל, חיווי פעולה ושורה אחת ביומן. אין זו הוכחת חיבור.
3. בוחרים „שתי פעולות” ומתחילים מחדש. אחרי הפעולה הראשונה מצופה 1 מתוך 2, והסבב נשאר פתוח. השנייה משלימה אותו. הקצב אינו נבדק; זהו ניסוי קשר פעולה–תגובה וספירת פעולות.
4. בודקים עצירה באמצע הדגמה, חזרה להתחלה וחזרה למצב גננת. הורדת JSON מפרידה מקור קלט, הודעות, תגובות נגינה, פעולות שנספרו וסבבים שהושלמו.
