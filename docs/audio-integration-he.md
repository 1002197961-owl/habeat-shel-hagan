## מה שונה

- טקסט מלא של כל הקלטה, כולל אפשרויות הבחירה, והדגשת המילה לפי זמני מילים של הקובץ עצמו.
- `data/narration.json` נגזר מ־forced alignment של Whisper small על 13 הקבצים ששוחזרו, עם תמליל מתוקן. אין חלוקת זמן משוערת לפי אורך המילים. ההדגשה קוראת `HTMLAudioElement.currentTime`, כולל קפיצה, עצירה וחידוש. לולאת הציור אינה שעון הניגון.
- השמעה חוזרת, עצירה, המשך וחזרה להתחלה; ביטול בקשות קודמות, שמע וטיימרים בעת מעבר שאלה/יציאה. לחיצות רצופות אינן מדלגות שאלות.
- שיר הקסם מתואר כמילים בלבד. הקראת התוצאה הדינמית נשארת קול דפדפן ומסומנת כך; אין לתוצאה קובץ שירה או לחן. לא נוספו תזמוני מילים מומצאים לטקסט הדינמי שאין לו הקלטה.
- הגופנים הם אותם קובצי Heebo מהפריסה, הנשמרים כעת מקומית כדי שהבנייה לא תהיה תלויה בהורדה בזמן build. הלוגו, מפת המותג, דמויות וסמלי הבית לא שונו.

## ספריית שירים

פרויקט Supabase היה מושהה והוחזר לפעילות. נשמר צילום נתוני הקטלוג ב־`docs/recovery/catalog-before-20260927.json`. המיגרציה `20260927100137_approve_song_recordings.sql` הוחלה על הפרויקט הקיים.

שלושת הקטעים המקוריים האינסטרומנטליים נשמרו. חמש רשומות שירים מוכרים היו מסומנות published למרות זכויות pending וללא הקלטה; כעת הן טיוטות שאינן נחשפות לקורא הציבורי. שום שיר מוכר או הקלטה חדשה לא אושרו או פורסמו.

להקלטה נדרשים אישור זכויות, הערת מקור/היתר, אישור הקלטה והערת ביקורת, משך, סוג sung/instrumental וגיבוב הקובץ. מסד הנתונים, RLS והלקוח אוכפים את התנאים. הלקוח מאמת גם את SHA-256 של הקובץ שהורד לפני השמעה. הנגן אינו מחליף הקלטה חסרה בליווי כאילו זו שירה.

לקליטה: מעתיקים `data/song-intake.example.json`, משלימים מטא־דאטה ומריצים:

```sh
node scripts/prepare-song.mjs song.json approved-source-audio.mp3 draft.json
```

השם בדוגמה אינו אישור: הפקודה מייצרת תמיד טיוטה pending/private, מחשבת גיבוב ואינה מעלה או מפרסמת. העלאה ל־song-audio, הסדרת זכויות וביקורת שמע ייעשו בנפרד ע״י גורם מוסמך; פרסום רק אחרי שתי הביקורות. שינוי הקובץ דורש ביקורת הקלטה חדשה. אין דוגמת שיר מוגן בקוד.

## בדיקה ושחזור

```sh
npm ci
npm test
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

אפשר לבחור מנוע מותקן ב־`TEST_ENGINES=chromium,chromium-mobile` ולספק נתיב דפדפן ב־`CHROMIUM_EXECUTABLE`. בדיקות E2E מפעילות שרת סטטי זמני על הפלט שנבנה; הן אינן פורסות. `PREVIEW_TEST_URL` מאפשר בדיקה חוזרת של גרסה זמינה. תוצאות מקומיות ב־test-results.

## מגבלות מסירה

דיוק גבולות המילים נקבע מתוך ההקלטה ונבדק מבנית, אך עדיין נדרשת האזנה אנושית במכשיר היעד לתיקון נקודתי של גבולות/תמליל אם יידרש. בדיקה אוטומטית של פענוח MP3, שעון נגן ומילה מודגשת אינה אישור לאיכות ההאזנה ברמקול פיזי. Safari/iOS ומכשיר הפיילוט לא נבדקו בסביבה הזאת.

המשך חיבור כלי פיזי, בקשת Arcana ופרוטוקול בדיקה מתועדים ב־`docs/hardware-pilot-he.md`. אין לראות בבדיקות הקלט הסינתטיות הוכחת חיבור.
